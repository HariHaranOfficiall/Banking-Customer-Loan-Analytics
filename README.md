# Banking Customer Loan Analytics

## Project Overview
This project analyzes banking customer and loan data to identify loan trends, understand customer behavior, and generate meaningful business insights using data analytics tools.

## Objectives
- Analyze customer and loan information.
- Identify loan approval and repayment trends.
- Track key performance indicators (KPIs).
- Create interactive dashboards to support data-driven decisions.

## Tools & Technologies
- **SQL / MySQL:** Data querying and analysis
- **Microsoft Power BI:** Interactive dashboard and visualization
- **Microsoft Excel:** Data cleaning and analysis

## Project Workflow
1. Collected and explored the banking customer loan dataset.
2. Cleaned and prepared data for analysis.
3. Used SQL queries to analyze customer and loan information.
4. Developed a Power BI dashboard to visualize key metrics.
5. Identified insights to support business decision-making.

## Key Insights
- Customer and loan distribution analysis.
- Loan status and approval trend analysis.
- Analysis of loan amounts and customer segments.
- KPI-based reporting for business insights.

## Project Structure
- `Dataset/` – Dataset files
- `SQL/` – SQL queries
- `PowerBI/` – Power BI dashboard files
